# 0.8-configurable-time

2026-11-05 更新。新增每天续火花时间选择，可设置北京时间的小时和分钟，默认22:00；保存后替换原排程，关闭自动任务时仍保留所选时间。

修复已开启但没有实际待执行闹钟时缺少恢复的问题。打开助手、重启、应用更新和时间变化后重新登记；同日过期排程可补查，跨日不补发昨天的消息。其他引擎检查占用时，在当天安全余量内安排一次延后检查。保留原有“今天已发过就跳过”及发送前持久化去重。

真实自动任务与只读演练分开记录，保留最近7天的汇总报告，包含原定、开始、结束时间及发送/跳过数量。超时保留已有发送计数，界面区分未执行、授权失效、后台启动受阻、超时和完成。旧版历史日期不足，不能精确复原先前漏执行的完整原因。

54项Node测试和55项Java时间/时区/恢复检查通过。真机验证了08:17保存并跨重开保留、恢复22:00后只有一份闹钟、强停后重开重新排程、15秒模拟唤醒，以及账号只读演练。安装包签名和真机安装文件校验值一致。本轮没有真实发送；正常自然触发批次仍待观察。

Android/OEM仍可能延迟；强行停止后需要重新打开助手。会话发现范围有限，未知、重燃中及不活跃状态保持跳过。公开文件排除账号会话、好友名单、消息正文、API密钥、签名私钥、设备截图和私人日志。
