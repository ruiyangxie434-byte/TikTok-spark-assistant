# 火花助手 · Android 手机后台版

版本：0.8-configurable-time。个人项目，不是抖音官方产品。

首次授权后在手机独立运行，按所选北京时间检查已识别的火花关系（默认22:00，可自选小时和分钟）。发送前读取当天服务端私聊记录：你今天已经发过消息或表情就跳过，不因对方尚未回复而重复发送。只有官方当前状态明确待续、且确认你今天没有发送的私聊，才尝试发送一个普通表情；已续、重燃中、未知、读取失败及当天已尝试的会话均跳过。发送前以账号/会话/北京时间日期持久化记录，发送后区分消息回执和官方点亮结果。

## 0.8 定时设置与恢复

点“续火花时间”可选择小时和分钟，按北京时间保存。修改后会替换原排程，关闭自动任务时也可先保存时间。默认保留22:00。打开助手、手机重启、应用更新或系统时间变化时会重新登记定时；当天过期但未触发的排程会安排补查，跨日不补发昨天的消息。强行停止会取消系统任务，需要重新打开一次助手。

真实自动任务保留最近7天的汇总记录（原定时间、开始/结束时间、发送和跳过数量），只读演练单独保存。界面显示最近自动任务的结果，区分未执行、授权失效、启动受阻、超时和完成。其他检查占用引擎时，自动任务在当天安全余量内安排一次延后检查；已有尝试记录仍然阻止重复发送。

## 目录与测试

`spark-engine/`包含Android源码、手机Node工作脚本、公开依赖及第三方许可；`background-streak-policy/`包含状态判断、去重、真实读取适配器和测试。

```sh
python spark-engine/build.py --test-only
```

## 构建

需要Python3.9+、Node.js、JDK、Android API36和Build Tools。设置JAVA_HOME、SPARK_ANDROID_JAR、SPARK_BUILD_TOOLS，可选SPARK_ECJ_JAR使用ECJ替代javac，然后执行：

```sh
python spark-engine/build.py
```

默认生成未签名APK。自行签名时设置SPARK_KEYSTORE、SPARK_KEYSTORE_PASSWORD，可选SPARK_KEY_ALIAS。签名材料不在仓库中；其他签名不能覆盖原签名安装包。

`spark-engine/vendor/runtime-arm64.zip.part*`（构建脚本自动合并）包含ARM64 Node.js Mobile18.20.4、官方NDKr24 libc++及JNI桥；`protocol.zip`来自MIT项目zhinjs/douyin-im固定提交f6eee669c39094224e00c6b877e1964d9da4e393及公开依赖，修改记录在压缩包内MOBILE-CHANGES.md。完整许可见licenses和THIRD_PARTY_NOTICES.txt。JNI桥源IR和构建脚本在native目录。

源码包不包含登录会话、用户账号数据、好友名单、API密钥、签名私钥、设备截图或日志。项目自有代码暂未指定开源许可证，第三方代码保持各自原许可。

## 安装与下载

安装包以分卷存放。下载[完整仓库ZIP](https://github.com/ruiyangxie434-byte/TikTok-spark-assistant/archive/refs/heads/main.zip)并解压，在仓库根目录执行：

```sh
python tools/unpack-apk.py
```

脚本会校验并生成 `artifacts/SparkBackground-0.8.apk`，不需要Android构建工具。校验值见[SHA256SUMS](artifacts/SHA256SUMS-0.8.txt)。可覆盖安装原签名版本并保留助手设置。

点“续火花时间”选择小时和分钟，保存后替换原排程。强行停止后需要重新打开一次助手恢复定时。54项Node测试、55项Java时间与恢复检查及真机只读验证通过；正常定时真实批次的验收仍待观察，详见[STATUS](docs/STATUS.md)。

0.6和0.7安装包分卷、0.3诊断目录保留为历史版本。当前源码请使用`spark-engine/`。
